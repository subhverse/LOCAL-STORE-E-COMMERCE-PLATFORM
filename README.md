OCAL STORE E-COMMERCE PLATFORM

A complete Local Store E-Commerce Platform built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

This project allows users to browse products, add items to cart, and place orders online through a secure and responsive e-commerce platform.

Features
User Authentication
JWT Secure Login System
Password Hashing using bcrypt
Product Listings
Product Search Functionality
Shopping Cart System
Add to Cart Feature
Remove from Cart
Checkout System
Protected Routes
Responsive E-Commerce UI
MongoDB Database Integration

Installation
Clone Repository
git clone https://github.com/subhverse/LOCAL-STORE-E-COMMERCE-PLATFORM.git
Install Dependencies
npm install
Run Server
npm start
Environment Variables

Create a .env file and add:

PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
